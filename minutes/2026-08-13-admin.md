## Meeting Recording Status

So far, the meeting recording solutions we have tested have been unsatisfactory. What we *want* is a fully-automatic recording/transcription system that can be accessed by any Admin team member, who can use it to generate meeting minutes. This helps us satisfy accountability and transparency goals for the organization.
* Jit.si baseline provides no recording capability
* Jit.si self-hosting has prohibitive hardware requirements
* Big Blue Button has a poor/unusable mobile user interface
* Brave Talk (hosted jit.si) doesn't seem to work for anyone except Joe
* Is it time to consider a commercial solution? FOSS so far has not provided adequate solutions.
